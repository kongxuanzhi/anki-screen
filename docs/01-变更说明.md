# 变更说明：哪些复用基座、哪些新增

## 一、复用（来自 vendored 基座 `mysphinx-snip` 0.0.1，MIT）

| 能力 | 复用位置 | 说明 |
|---|---|---|
| 屏幕抓取（多显示器 / HiDPI） | `base/capture.py` | 每屏 `QScreen.grabWindow`，自动带 `devicePixelRatio` |
| 选区交互 | `base/overlay.py` | 拖拽创建、移动、八手柄缩放、尺寸标签、Esc 取消 |
| 箭头 | `base/annotations.py` `ArrowAnnotation` | 含线段命中检测与箭头头绘制 |
| 文字 | `base/annotations.py` `TextAnnotation` | 行内 `QLineEdit` 输入逻辑在 `editor_canvas` 中沿用同样手法 |
| 撤销 / 重做 | `base/annotations.py` `AnnotationStack` | 挖空、箭头、文字共用同一个栈 |
| 系统托盘 | `base/app.py` `SnipApp._build_tray` | 右键菜单、通知气泡 |
| 全局热键（兜底路径） | `base/app.py` `SnipApp._install_hotkey_pynput` | `pynput.GlobalHotKeys`，原生注册失败时才用；macOS 需要「辅助功能」 |
| macOS 权限检测 | `base/permissions.py` | 辅助功能 / 屏幕录制检测 + 系统设置跳转 |
| 配置存储 | `base/config.py` | `Settings` 继承它，只替换 `QSettings` 作用域 |
| 配色 / 线宽默认值 | `base/annotations.py` `Style` | 沿用 |

**一句话**：截图、选区、箭头、文字、撤销重做、托盘 —— 一行都没重写。

> 唯一例外是**全局热键**：上游只用 pynput，在 macOS 上必须授予「辅助功能」，
> 否则监听器静默失效（表现正是"点托盘能截图、按快捷键没反应"）。
> 这里把热键注册换成"原生优先 + pynput 兜底"，详见第三节与
> `docs/03-阶段交付记录.md`。

## 二、基座改动（3 个文件 · 8 处，均带 `AnkiSnip 注入` 注释）

| 文件 | 改动 |
|---|---|
| `base/annotations.py` | ① `ToolType.MASK = "mask"`；② `MaskAnnotation`（继承 `_TwoPointAnnotation`，半透明填充 + 虚线边框，`to_norm()/from_norm()`）；③ `_TOOL_CLASSES[ToolType.MASK] = MaskAnnotation`；④ `AnnotationStack.remove()` |
| `base/toolbar.py` | `_TOOLS` 增加挖空按钮 |
| `base/app.py` | ⑤ 新增两个类属性钩子 `overlay_cls` / `config_cls`，让子类替换实现而不必复制 `start_capture()`；⑥ `_install_hotkey` 改为调用 `ankisnip.hotkey.GlobalHotkeyManager`（上游实现保留为 `_install_hotkey_pynput` 兜底）；⑦ 新增 `reload_hotkey()` / `hotkey_status_text()`；⑧ `_set_capture_label` 展示人类可读热键，失败时显式写「热键未生效」；⑨ **托盘菜单改用 `setContextMenu(menu)`**（macOS 上是原生 `NSStatusItem.menu`，由 AppKit 管理弹出 / 焦点 / Esc / 高亮 / 菜单项派发；左键和右键都会弹菜单，「截图」在第一项）；⑩ 启动时先记录一次前台 App，作为截图 / 对话框收起后的兜底交接目标；⑪ 非 macOS 保留 `activated(Trigger)` → 直接截图（Windows / Linux 仍是左键截图、右键菜单）；⑫ 「截图」菜单项同时设置与全局热键相同的 `QKeySequence`（菜单打开时 Carbon 热键被系统挡住，由 AppKit 的 key equivalent 触发；macOS 上 Qt 的 Ctrl/Meta 语义对调）；⑬ 截图覆盖层通过 `NSWindow.level = NSScreenSaverWindowLevel` 抬到菜单栏之上，可框选菜单栏 |

`base/VENDORED.md` 记录了来源、许可证依据与逐处改动。

## 三、新增模块

| 模块 | 为什么必须新增 |
|---|---|
| `coords.py` | 基座覆盖层没有视图变换；验收第 3 条（400% → 100% 不变）要求一个明确的缩放 / 平移模型，并且要求它是**唯一出入口** |
| `editor_canvas.py` | 可缩放 / 平移的画布 + 鼠标交互（创建 / 选中 / 移动 / 删除 / 手柄 / 行内文字）。仍然复用基座的标注类与栈 |
| `editor_toolbar.py` | 基座 `CaptureToolbar` 是**选区浮动条**（复制 / 保存 / 贴图 / 完成 / 取消），语义与标注不同，故另起一份；工具集合与 `Style` 仍来自基座。两行上下文布局：第一行常驻（回到选区 / 主工具 / 撤销重做 / 缩放菜单 / 更多 / 复制 / 保存 / 取消），第二行按工具显示 7 色 / 线宽 / 字号；矩形 / 椭圆 / 高亮 / 保存图片收进「⋯」 |
| `mask_colors.py` | 图片挖空模板的 7 色定义（含语义标签）与颜色归一化；历史 `pen_color` 在进入覆盖层时收敛到模板支持色 |
| `overlay_ext.py` | ① **选区与标注合一**：`Phase.SELECT`（选区可拖可拉伸，沿用基座鼠标逻辑）↔ `Phase.DRAW`（把 `EditorCanvas` 作为**子控件**挂到选区矩形上就地标注，不再弹独立窗口）；② 按**原图分辨率**取选区图（比例反推设备像素，绕开 `toImage()` 的 dpr 语义差异）；③ 标注栈由覆盖层持有，画布在两阶段之间销毁重建也不丢 |
| `rasterize.py` | 烧录导出：按类型分离挖空、按原图分辨率栅格化；`bake_including_masks()` 供复制/另存把遮挡画进图 |
| `kong/` | 现有插件 `kong` 序列化的 Python 移植（见 `docs/02-kong协议说明.md`） |
| `anki_connect.py` | AnkiConnect HTTP 客户端（只用标准库 `urllib`） |
| `apkg_export.py` | genanki 离线导出；**优先用笔记类型的真实模板快照**（模型 id / 字段 / 模板 / CSS），没快照时才退回最小模板并显式告警 |
| `template_store.py` | 新增。趁 Anki 在线抓取笔记类型定义存为快照（`~/Library/Application Support/ankisnip/templates/`），离线导出时取用 |
| `saver.py` | 保存链路编排 + 失败 / 取消时的媒体清理 |
| `hotkey.py` | 全局热键统一层：记法解析 → 平台原生注册（macOS Carbon `RegisterEventHotKey` / Win32 `RegisterHotKey`，都不需要辅助功能权限）→ pynput 兜底；支持热重载与可读状态 |
| `hotkey_capture.py` | 热键录制控件：按下组合键自动生成记法（`/<65>` 形式的原始键码作为逃生舱），录制期间挂起已注册热键 |
| `settings.py`、`settings_dialog.py` | 牌组 / 笔记类型 / 字段映射 / 端口 / 离线目录等配置 |
| `logging_setup.py` | 日志文件 |
| `app.py` | `SnipApp` 子类：托盘菜单（左键截图 / 右键菜单）、`anki` 动作、保存回调、首次运行引导 |

## 四、明确没有做的事

* 没有从 Anki 源码里抽 `AnkiWebView`。
* 没有把 Snipaste 作为依赖。
* 没有重写截图 / 选区 / 箭头 / 文字 / 撤销重做 / 托盘；全局热键只换了注册后端
  （原生优先），上游 pynput 实现原样保留为兜底。
* 没有把屏幕像素写进 `kong`（持久化链条是 image px → 归一化 → 百分比字符串）。
* 没有修改现有 Anki 模板的 `kong` 格式（对拍已证明逐字节一致）。
* 没有把挖空遮罩烧录进图片（`rasterize.split_annotations` + 单测覆盖）。
